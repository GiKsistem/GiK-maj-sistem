01 Upload Data

Minimal upload Daftar Toko dulu. Data Penjualan / Tagihan boleh menyusul kapan saja — tombol hitung tetap bisa jalan dengan data yang tersedia.
Daftar Toko
Master toko + kode + wilayah. Upload sekali, replace kalau ada toko baru.
Mode: Replace · Wajib
Belum ada data
Data Penjualan
Export transaksi (flat file). Upload tiap minggu — histori otomatis ditambahkan.
Mode: Tambah / Merge
Belum ada data
Data Tagihan (Aging Piutang)
Aging piutang semua toko (dalam kota & luar kota jadi satu file). Sistem otomatis pisahkan: kode PDG/KRY = dalam kota, selain itu = luar kota. Upload tiap ada update — menggantikan data lama.
Mode: Replace
Belum ada data
"Backup Data" menyimpan SEMUA data website ini (toko, tagihan, riwayat lunas, log kunjungan, dll) ke 1 file .json. Kalau pindah/ganti laptop, buka website ini di laptop baru lalu klik "Restore Backup" dan pilih file .json tadi — semua data akan kembali seperti semula.
