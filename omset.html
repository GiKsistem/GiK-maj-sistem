Data otomatis tersimpan di browser laptop ini. Bisa pulihkan beberapa file cadangan berturut-turut, otomatis digabung.

Daftar Toko

Master toko dipakai untuk menentukan Wilayah tiap toko. Kategori Padang / Motoris / Luar Kota / Sales Counter dihitung otomatis dari kode toko, tidak perlu diisi manual.

Kode TokoNamaWilayahKategori (otomatis)

Target Bulanan

Isi target omset per Wilayah / Divisi / bulan. Target Matic dan Target AOS dihitung otomatis (35% AP2, 55% ATI, 45% ATU, 35% FP2 dari target; AOS = 30% dari total target divisi).

Upload Data Penjualan

Upload flat file penjualan (kumulatif dari awal bulan). Data bulan yang sama akan menggantikan (bukan menumpuk) data sebelumnya. Perhitungan pakai kolom DPP.

Laporan Pencapaian

Kuning = omset di bawah Rp1.000.000 Merah = omset kosong / tidak jualan

Target Capaian per Salesman

Klik salah satu persen, atau isi sendiri — kekurangan omsetnya otomatis muncul.

Target QTY & KPI

Target QTY per SKU (kode L4) dicocokkan otomatis ke kolom "MG 4" di flat file penjualan. KPI (Collection, OA, SKU, Qty) per Wilayah/Divisi — Collection Anda isi manual, sisanya dihitung otomatis dari data yang sudah diupload.

KPI Ringkas

Target QTY per SKU (kode L4)

Kolom Target bisa diedit langsung (klik, ketik, otomatis tersimpan). Kolom Act & Ach% dihitung otomatis.

L4 Transaksi

Jumlah toko yang transaksi di tiap kode L4 pada bulan yang dipilih (Act), dibandingkan dengan Target OA. Satu toko dihitung 1 per L4 per bulan, berapa pun qty-nya, selama total qty bersihnya (setelah retur) lebih dari 0. Kolom Target OA bisa diedit langsung.

Hijau = capai 80% atau lebih Merah = di bawah 30%

Insentif Salesman

Terisi otomatis dari target, flat file, KPI, dan L4. Kolom bertanda kuning diisi manual lalu tersimpan otomatis.
