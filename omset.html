Daftar Toko

Master toko dipakai untuk menentukan Wilayah tiap toko. Kategori Padang / Motoris / Luar Kota / Sales Counter dihitung otomatis dari kode toko, tidak perlu diisi manual.

Target Bulanan

Isi target omset per Wilayah / Divisi / bulan. Target Matic dan Target AOS dihitung otomatis (36% AP2, 58.3% ATI, 34.2% ATU, 32% FP2 dari target; AOS = 30% dari total target divisi).

Upload Data Penjualan

Upload flat file penjualan (kumulatif dari awal bulan). Data bulan yang sama akan menggantikan (bukan menumpuk) data sebelumnya. Perhitungan pakai kolom DPP.

Laporan Pencapaian

Kuning = omset di bawah Rp1.000.000 Merah = omset kosong / tidak jualan

Target Capaian per Salesman

Target QTY & KPI

Target QTY per SKU (kode L4) dicocokkan otomatis ke kolom "MG 4" di flat file penjualan. KPI (Collection, OA, SKU, Qty) per Wilayah/Divisi — Collection Anda isi manual, sisanya dihitung otomatis dari data yang sudah diupload.
